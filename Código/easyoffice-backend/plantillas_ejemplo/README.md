# Plantillas de ejemplo

Word de ejemplo para probar la pantalla **Plantillas** del panel sin necesitar los documentos oficiales de Easy Office. Se suben desde el panel (menú Plantillas, con una cuenta administrador); no se leen desde esta carpeta.

| Archivo | Servicio | Nota |
|---|---|---|
| `Contrato_de_servicio_EJEMPLO.docx` | Contrato de servicio | Basado en el modelo OFICINA de Easy Office. Los datos del cliente están reemplazados por marcas, sin datos bancarios, sin fotos y con los datos personales del representante tapados. |
| `Autorizacion_domicilio_tributario_FICTICIA.docx` | Autorización de domicilio tributario | Documento inventado, con un aviso rojo en cada página. Reemplazar por el modelo oficial. |

## Marcas

Una marca es el lugar del Word donde el sistema pondrá un dato. Se aceptan dos formatos:

- Campos de combinar correspondencia de Word (`MERGEFIELD`), como los del contrato de Easy Office.
- Texto con dobles llaves, por ejemplo `{{RAZON_SOCIAL}}`.

El panel lista las marcas disponibles. Si el archivo trae una marca que no está en el catálogo, no se acepta.

## Plantillas reales

Cuando Easy Office entregue sus documentos oficiales, se suben por el panel y no se agregan al repositorio.
